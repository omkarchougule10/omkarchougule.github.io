About

I test like the user hasn't read the instructions.

I got into QA because I like being the person who asks "but what if the user does this instead?" — the edge case, the malformed input, the request that arrives out of order. During my internship at Ascensify Technologies, that instinct turned into a job: manual and regression testing across web and software applications, detailed test case authoring, and defect reports developers can actually act on.

Outside of manual testing, I'm building toward automation — comfortable with Python for scripting and SQL for data validation, and currently sharpening my Selenium and Playwright skills so I can pair QA judgment with automated coverage at scale.
